# 俄罗斯方块 (Tetris) for ESPboy

一个为ESPboy/Arduboy设计的经典俄罗斯方块游戏。

## 游戏特性

- ✅ 经典的俄罗斯方块玩法
- ✅ 7种不同的方块形状
- ✅ 计分系统和等级系统
- ✅ 最高分保存（使用EEPROM）
- ✅ 下一个方块预览
- ✅ 暂停功能
- ✅ 流畅的60FPS游戏体验

## 操作说明

### 菜单界面
- **B键** - 开始游戏

### 游戏中
- **左方向键** - 向左移动方块
- **右方向键** - 向右移动方块
- **上方向键** - 旋转方块
- **下方向键** - 加速下落
- **B键** - 瞬间下落（硬降）
- **A键** - 暂停/继续游戏

### 暂停界面
- **A键** - 继续游戏

### 游戏结束界面
- **B键** - 返回主菜单

## 游戏规则

### 计分系统
- 方块自然下落：每格 1 分
- 加速下落：每格 1 分
- 瞬间下落：每格 2 分
- 消除行数奖励：
  - 1行：100 × 等级
  - 2行：300 × 等级
  - 3行：500 × 等级
  - 4行：800 × 等级

### 等级系统
- 每消除10行升1级
- 等级越高，方块下落速度越快
- 最高等级：无限制

### 方块类型
游戏包含7种经典的俄罗斯方块：
1. **I形** - 直线方块（4格）
2. **O形** - 正方形方块（2×2）
3. **T形** - T字形方块
4. **S形** - S字形方块
5. **Z形** - Z字形方块
6. **J形** - J字形方块
7. **L形** - L字形方块

## 编译和上传

### 1. 打开项目
在Arduino IDE中打开 `tetris.ino`

### 2. 选择开发板
- 工具 → 开发板 → ESP8266 Boards → NodeMCU 1.0 (ESP-12E Module)

### 3. 配置参数
- CPU频率：160 MHz
- Flash Size：4MB (FS:2MB OTA:~1019KB)
- Upload Speed：115200

### 4. 编译上传
点击"上传"按钮

## 技术细节

### 内存使用
- 游戏板：200 bytes (10×20)
- 方块数据：112 bytes (7种方块)
- 游戏变量：约50 bytes
- 总计：约400 bytes RAM

### 性能优化
- 使用PROGMEM存储方块形状数据
- 高效的碰撞检测算法
- 60FPS流畅运行
- 优化的绘图代码

### EEPROM使用
- 地址100-103：最高分（4字节，uint32_t）

## 游戏技巧

1. **提前规划** - 注意"下一个"方块预览
2. **留空间** - 不要让方块堆得太高
3. **消多行** - 尽量一次消除多行获得更高分数
4. **快速旋转** - 熟练使用旋转功能
5. **硬降技巧** - 在确定位置后使用B键快速下落

## 已知问题

- 无音效（ESP8266音频支持有限）
- 方块大小固定为3×3像素（受屏幕尺寸限制）
