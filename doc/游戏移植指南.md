## 快速移植步骤

### 1. 下载Arduboy游戏
从以下来源获取游戏：
- https://github.com/arduboy/arduboy (官方游戏集合)
- https://community.arduboy.com/ (社区游戏)
- https://github.com/topics/arduboy (GitHub搜索)

### 2. 复制到项目
```
ESP8266_RetroPocket_Arduboy/
  games/
    your-game/          ← 创建游戏文件夹
      your-game.ino     ← 主文件
      *.h               ← 头文件
      *.cpp             ← 源文件
```

### 3. 编译测试
1. 在Arduino IDE中打开 `your-game.ino`
2. 选择开发板：`NodeMCU 1.0 (ESP-12E Module)`
3. 点击"验证/编译"

### 4. 处理编译错误（如果有）

#### 错误类型A：音频相关
```
错误：ArduboyTones.h: No such file
```

**解决方案：**
```cpp
// 在文件开头添加
#ifndef ESP8266
#include <ArduboyTones.h>
#endif

// 在使用音频的地方
#ifndef ESP8266
  sound.tone(1000, 100);
#endif
```

#### 错误类型B：AVR特定代码
```
错误：'PROGMEM' was not declared
```

**解决方案：**
```cpp
// ESP8266已经支持PROGMEM，通常不需要修改
// 如果报错，确保包含了：
#include <pgmspace.h>
```

#### 错误类型C：定时器/寄存器
```
错误：'TCCR1A' was not declared
```

**解决方案：**
```cpp
// 这是AVR硬件定时器，ESP8266不支持
// 用 #ifndef ESP8266 包裹或删除相关代码
#ifndef ESP8266
  TCCR1A = 0;
#endif
```

## 兼容性检查清单

在移植前，检查游戏代码：

### ✅ 高兼容性（无需修改）
- [ ] 只使用 `Arduboy2.h`

- [ ] 直接操作AVR寄存器
- [ ] 使用AVR汇编代码

## 性能优化建议

### 内存使用
```
当前游戏 (arduman):
- 程序空间：283248 bytes (27%)
- 动态内存：29020 bytes (35%)
- 剩余空间：充足
```

### 如果遇到内存不足

1. **减少全局变量**
```cpp
// 不好
uint8_t bigArray[1000];

// 好
const uint8_t bigArray[1000] PROGMEM = {...};
```

2. **使用PROGMEM存储常量**
```cpp
const uint8_t sprite[] PROGMEM = {
  // 精灵数据
};
```

3. **优化字符串**
```cpp
// 不好
arduboy.print("Very long string...");

// 好
arduboy.print(F("Very long string..."));
```

## 上传到硬件

### 1. 连接ESP8266
- 使用USB数据线连接NodeMCU
- 确保驱动已安装（CH340）

### 2. 选择正确的COM口
- 工具 → 端口 → 选择你的ESP8266端口
- Windows: COM3, COM4, COM5等
- 如果看不到端口，检查驱动和USB线

### 3. 上传设置
```
开发板：NodeMCU 1.0 (ESP-12E Module)
CPU频率：160 MHz
Flash Size：4MB (FS:2MB OTA:~1019KB)
Upload Speed：115200
```

### 4. 上传
- 点击"上传"按钮
- 等待编译和上传完成
- 游戏会自动启动

## 常见问题

### Q: 游戏运行很慢？
A: 
- 确保CPU频率设置为160MHz
- 检查是否有大量的浮点运算
- 优化绘图代码（减少重复绘制）

### Q: 显示不正常？
A: 
- 检查I2C接线（SDA=D2, SCL=D1）
- 确认OLED地址为0x3C
- 尝试调用 `oled.flipScreenVertically()`

### Q: 按键不响应？
A: 
- 检查按键接线是否正确
- 确认按键引脚定义（见相关信息.md）
- 测试按键是否有物理问题

### Q: 编译时内存不足？
A: 
- 使用PROGMEM存储大数组
- 减少全局变量
- 优化代码结构
