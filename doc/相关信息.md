# ESP8266 复古游戏机 (Arduboy)

## 硬件材料

| 名称 | 型号/规格 |
|------|-----------|
| 主控板 | NodeMCU v3 Type-C CH340 ESP8266-12E |
| 屏幕 | 0.96寸 OLED SSD1315 I2C 四针 黄蓝色 |
| 按键 | 微动按钮 |

## 引脚定义

### 按键引脚

| 功能 | GPIO | NodeMCU 引脚 |
|------|------|--------------|
| UP | 14 | D5 |
| DOWN | 12 | D6 |
| LEFT | 13 | D7 |
| RIGHT | 0 | D3 |
| A | 2 | D4 |
| B | 3 | RX |

### OLED I2C 接线

| OLED 引脚 | NodeMCU 引脚 | 说明 |
|-----------|--------------|------|
| GND | GND | 地线 |
| VCC | 3.3V | 电源 (ESP8266 是 3.3V 逻辑) |
| SCL | D1 (GPIO 5) | I2C 时钟线 |
| SDA | D2 (GPIO 4) | I2C 数据线 |

## 开发环境

- **IDE**: Arduino IDE 2.3.6
- **驱动**: CH340 驱动
- **插件**: LittleFS Filesystem Uploader v1.6.0

## 依赖库

| 库名 | 用途 |
|------|------|
| brzo_i2c | 快速 I2C 通信 |
| SSD1306Brzo | OLED 驱动 (基于 brzo_i2c) |
