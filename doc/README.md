# 文档总览

本目录用于沉淀项目文档，按“复刻 -> 上传 -> 移植 -> 路线图”组织。

## 核心文档

- `相关信息.md`：硬件与开发环境速查
- `上传指南.md`：Windows 上传与串口排错
- `游戏移植指南.md`：Arduboy 到 ESP8266 的标准移植流程
- `游戏开发教程.md`：新游戏开发起步流程
- `ESPboy_Arduboy_Port.md`：复刻与背景说明

## 开源治理与规划

- `OPEN_SOURCE_INDEX.md`：开源协作入口索引
- `open-source-roadmap/ROADMAP.md`：项目路线图

## 维护建议

1. 新增流程文档时，先更新本文件目录索引。
2. 涉及路径变更时，同步更新 `readme.md` 与相关指南。
3. 文档中的参数（板卡、频率、路径）应与当前仓库结构一致。
