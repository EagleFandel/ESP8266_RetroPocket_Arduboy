# ESP8266 上传指南（Windows）

本指南用于解决“识别不到串口 / 上传失败 / 上传后不运行”等常见问题。

## 1. 上传前检查

### 1.1 IDE 参数

- 开发板：`NodeMCU 1.0 (ESP-12E Module)`
- CPU：`160 MHz`
- Flash Size：`4MB (FS:2MB OTA:~1019KB)`
- Upload Speed：`115200`
- 端口：选择设备管理器中的实际 COM 口

### 1.2 硬件状态

- 使用支持数据传输的 USB 线（非纯充电线）
- 开发板供电正常（电源灯亮）
- 上传时不要按住 `RIGHT`（D3/GPIO0）

## 2. 找不到 COM 口怎么办

### 2.1 先看设备管理器

1. `Win + X` → 设备管理器
2. 打开“端口(COM 和 LPT)”
3. 查找类似：
   - `USB-SERIAL CH340 (COMx)`
   - `Silicon Labs CP210x (COMx)`

### 2.2 没有端口或有黄色感叹号

- 安装对应驱动（CH340 / CP2102）
- 更换 USB 口与 USB 线
- 重启电脑后再试

## 3. 上传失败排查

### 3.1 典型错误：`could not open port 'COMx'`

可能原因：

- 端口号选错
- 串口被其他程序占用（串口监视器、第三方工具）
- 设备掉线

处理方式：

1. 关闭串口监视器与其他串口软件
2. 重新插拔 USB
3. 重新选择正确 COM 口

### 3.2 典型错误：`Failed to connect` / `Timed out waiting for packet header`

可能原因：

- 板子未进入下载阶段
- GPIO0 状态异常（如误按 D3 键）

处理方式：

1. 点击上传后观察日志
2. 如需手动介入，可按住板载 `FLASH`，看到 `Connecting...` 后松开
3. 上传全过程避免按任何外接按键

## 4. 上传后不运行排查

1. 按 `RST` 重启
2. 检查 OLED 接线（`SCL=D1`, `SDA=D2`）
3. 检查是否误触发了 GPIO0 启动条件
4. 打开串口监视器查看启动日志（常用 115200）

## 5. PowerShell 快速诊断

```powershell
# 查看当前串口
[System.IO.Ports.SerialPort]::GetPortNames()

# 查看设备模式信息
mode
```

## 6. 推荐上传流程（稳定版）

1. 连接开发板并等待系统识别
2. 在设备管理器确认 COM 口
3. 在 Arduino IDE 选择正确板卡和端口
4. 先“验证”再“上传”
5. 上传期间不要按任何外接按键
