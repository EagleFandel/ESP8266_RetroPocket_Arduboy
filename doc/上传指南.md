# ESP8266上传指南

## 问题：找不到COM端口

### 错误信息
```
serial.serialutil.SerialException: could not open port 'COM5'
```

## 解决步骤

### 1. 检查设备连接

#### Windows系统
1. **打开设备管理器**
   - 按 `Win + X`
   - 选择"设备管理器"

2. **查找端口**
   - 展开"端口(COM和LPT)"
   - 查找类似以下的设备：
     - `USB-SERIAL CH340 (COM3)`
     - `Silicon Labs CP210x (COM4)`
     - `USB Serial Port (COM6)`

3. **记下正确的COM端口号**

#### 常见情况
- ✅ 看到COM端口 → 记下端口号
- ❌ 没有COM端口 → 需要安装驱动
- ⚠️ 端口有黄色感叹号 → 驱动有问题

### 2. 安装驱动（如果需要）

#### NodeMCU常用驱动

**CH340驱动** (最常见)
- 下载地址：http://www.wch.cn/downloads/CH341SER_EXE.html
- 或搜索："CH340驱动下载"

**CP2102驱动**
- 下载地址：https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
- 或搜索："CP2102驱动下载"

#### 安装步骤
1. 下载对应的驱动程序
2. 解压并运行安装程序
3. 重启电脑
4. 重新连接ESP8266
5. 在设备管理器中确认端口出现

### 3. 在Arduino IDE中选择正确端口

1. **工具 → 端口**
2. 选择你在设备管理器中看到的COM端口
3. 例如：`COM3` 或 `COM4`

### 4. 上传程序

1. 确保ESP8266已连接
2. 点击"上传"按钮
3. 等待上传完成

## 上传设置检查清单

### Arduino IDE设置
```
✅ 开发板：NodeMCU 1.0 (ESP-12E Module)
✅ CPU频率：160 MHz
✅ Flash Size：4MB (FS:2MB OTA:~1019KB)
✅ Upload Speed：115200
✅ 端口：正确的COM端口
```

### 硬件检查
```
✅ USB线已连接
✅ USB线支持数据传输（不是只充电的线）
✅ ESP8266电源指示灯亮起
✅ 驱动已正确安装
```

## 常见问题

### Q1: 设备管理器中没有COM端口
**原因：** 驱动未安装或USB线不支持数据传输

**解决：**
1. 更换USB数据线（确保支持数据传输）
2. 安装CH340或CP2102驱动
3. 尝试不同的USB端口

### Q2: 上传时提示"连接超时"
**原因：** ESP8266未进入下载模式

**解决：**
1. 按住ESP8266的FLASH按钮
2. 点击Arduino IDE的"上传"
3. 看到"Connecting..."时松开FLASH按钮

### Q3: 上传速度很慢
**原因：** 波特率设置过低

**解决：**
- 尝试不同的Upload Speed：
  - 115200 (推荐)
  - 921600 (更快，但可能不稳定)
  - 57600 (更慢，但更稳定)

### Q4: 上传后程序不运行
**原因：** 程序卡在启动阶段

**解决：**
1. 按ESP8266的RST按钮重启
2. 断开USB重新连接
3. 检查串口监视器的输出信息

## 验证上传成功

### 方法1：观察LED
- 上传过程中，ESP8266的LED会快速闪烁
- 上传完成后，LED停止闪烁
- 程序开始运行

### 方法2：串口监视器
1. 工具 → 串口监视器
2. 设置波特率：115200
3. 查看输出信息

### 方法3：屏幕显示
- 如果OLED已连接，应该看到游戏画面
- 俄罗斯方块：显示"TETRIS"菜单

## 快速诊断

运行以下命令检查端口：

### Windows PowerShell
```powershell
# 列出所有COM端口
[System.IO.Ports.SerialPort]::getportnames()

# 或使用mode命令
mode
```

### 设备管理器快捷方式
```
Win + R → devmgmt.msc → 回车
```

## 推荐的上传流程

1. ✅ 连接ESP8266到电脑
2. ✅ 等待3-5秒让系统识别设备
3. ✅ 打开设备管理器确认COM端口
4. ✅ 在Arduino IDE中选择正确端口
5. ✅ 点击"验证"确保代码无误
6. ✅ 点击"上传"
7. ✅ 等待上传完成
8. ✅ 观察ESP8266重启并运行程序

## 如果仍然无法上传

### 尝试以下方法

1. **重启Arduino IDE**
2. **重启电脑**
3. **更换USB端口**
4. **更换USB线**
5. **检查ESP8266是否损坏**
6. **尝试使用其他电脑**

### 获取帮助

如果以上方法都不行，可以：
1. 查看Arduino IDE的详细错误信息
2. 搜索具体的错误代码
3. 访问ESP8266社区论坛
4. 检查硬件是否有物理损坏
